## 1. 模式切换与文字输入

| 模式 | 主要作用 | 进入方式 | 返回 Normal |
|---|---|---|---|
| Normal | 移动光标、复制、删除等 | 启动 Vim 后通常处于此模式 | — |
| Insert | 输入文字 | `i`、`a`、`o`、`O` | `Esc` |
| Visual | 选择文字，再执行操作 | `v` 按字符选择；`V` 按整行选择 | `Esc` |
| Replace | 连续覆盖已有字符 | `R` | `Esc` |
| 命令行模式 | 保存、退出、搜索等 | Normal 下按 `:`、`/`、`?` | `Esc` 取消；Enter 执行 |

`j` 在 Normal 中向下移动，在 Insert 中输入字母，在 Visual 中移动选区的活动端点。`j` 本身不是进入 Visual 模式的按键。

| 按键 | 输入位置或作用 |
|---|---|
| `i` / `a` | 在光标前／后进入 Insert |
| `I` / `A` | 在本行第一个非空白字符前／行尾进入 Insert |
| `o` / `O` | 在本行下方／上方新建一行并进入 Insert |
| `Esc` / `Ctrl+[` | 离开 Insert，返回 Normal |
| `Ctrl+w`（Insert） | 删除光标前的一个词 |
| `Ctrl+u`（Insert） | 删除当前插入段在本行中光标之前的文本，细节受插入起点影响 |
| `Ctrl+n` / `Ctrl+p`（Insert） | 按缓冲区等来源补全关键词，向后／向前选择候选 |

`o` 不只是创建新行，还切换了模式；`o` 后按 `j` 会输入字母。[Vim 插入命令参考](https://vimhelp.org/insert.txt.html)

Vim 的命令行模式属于编辑器内部。例如 `:w` 保存当前缓冲区到文件；它不是 Ubuntu Shell。

## 2. 光标移动：字符、单词、行与文件

| 按键（Normal 模式） | 作用 |
|---|---|
| `h`、`j`、`k`、`l` | 左、下、上、右 |
| `0` | 移动到本行第一个字符，包括开头的空白 |
| `^` | 移动到本行第一个非空白字符 |
| `$` | 移动到行尾 |
| `w` / `b` | 向后／向前移动到词开头 |
| `e` / `ge` | 向后／向前移动到词尾 |
| `W` / `B` / `E` | 按空白分隔的大词移动，标点不会单独划分大词 |
| `gg`、`G` | 移动到文件第一行／最后一行 |
| `5j`、`10G` | 向下移动 5 行／跳到第 10 行 |
| `:10` | 跳到第 10 行，需要 Enter |
| `f{字符}` / `F{字符}` | 在本行向右／向左找到字符并停在其上 |
| `t{字符}` / `T{字符}` | 在本行向右／向左找到字符，停在抵达该字符之前的位置 |
| `;` / `,` | 同方向／反方向重复最近的 `f/F/t/T` |
| `%` | 在匹配的括号间跳转，如 `()`、`[]`、`{}` |
| `{` / `}` | 跳到前一个／后一个段落边界 |
| `gj` / `gk` | 按屏幕显示行向下／向上移动，适合一行文字自动折行时 |

例如下面一行开头有四个空格：

```cpp
    return 0;
```

在 Normal 模式中，`0` 停在第一个空格上，`^` 停在字母 `r` 上。编辑带缩进的 C++ 代码时，`^` 可以直接跳过缩进。[Vim 光标移动参考](https://vimhelp.org/motion.txt.html#left-right-motions)

## 3. 屏幕滚动与定位

| 按键（Normal） | 作用 |
|---|---|
| `Ctrl+d` / `Ctrl+u` | 向下／向上滚动半屏，按默认滚动设置 |
| `Ctrl+f` / `Ctrl+b` | 向下／向上翻一屏 |
| `Ctrl+e` / `Ctrl+y` | 向下／向上滚动一行 |
| `H` / `M` / `L` | 移动到当前窗口顶部／中部／底部的文本行 |
| `zz` / `zt` / `zb` | 将光标所在行放到窗口中部／顶部／底部 |

`gg/G` 按整个文件定位，`H/M/L` 按当前窗口定位，`zz` 调整视图位置。[Vim 滚动参考](https://vimhelp.org/scroll.txt.html)

## 4. 删除、修改、替换与合并

| 按键（Normal） | 作用与模式变化 |
|---|---|
| `x` / `X` | 删除光标上的／前面的字符，保持 Normal |
| `dd` / `3dd` | 删除当前行／从当前行开始的三行 |
| `dw` | 删除到下一词开头，通常包含词后的空白 |
| `de` | 删除到当前或下一词的词尾，包含词尾字符 |
| `d$` / `D` | 从光标处删除到本行行尾 |
| `d0` | 删除光标前到行首的文本，不包含光标上的字符 |
| `r{字符}` | 将光标上的一个字符替换成指定字符，保持 Normal |
| `R` | 进入 Replace，持续覆盖文字；按 Esc 结束 |
| `s` | 删除光标上的字符并进入 Insert |
| `cc` / `S` | 修改整行并进入 Insert，缩进受相关设置影响 |
| `c$` / `C` | 从光标处修改到行尾并进入 Insert |
| `ciw` | 修改光标所在的整个词并进入 Insert |
| `J` | 合并当前行和下一行，按规则处理空白 |
| `gJ` | 合并当前行和下一行，不额外增删连接处的空白 |

`d` 是删除，`c` 是删除指定范围后开始输入。Vim 中的删除通常还会把内容放入寄存器，因此可以用 `p` 放回；尚未保存的编辑可用 `u` 撤销。[Vim 编辑命令参考](https://vimhelp.org/change.txt.html)

## 5. 复制、粘贴与寄存器

| 按键（Normal） | 作用 |
|---|---|
| `yy` / `3yy` | 复制当前行／从当前行开始的三行 |
| `yw` | 复制到下一词开头的范围 |
| `yiw` | 复制光标所在的整个词 |
| `y$` | 复制从光标到本行行尾的内容 |
| `p` / `P` | 字符内容放在光标后／前；整行内容放在当前行下／上 |
| `"ayy` | 把当前行复制到命名寄存器 `a` |
| `"ap` | 粘贴寄存器 `a` 的内容 |
| `"0p` | 粘贴最近一次普通复制保存到寄存器 `0` 的内容 |
| `:registers` | 查看寄存器内容 |

普通复制、删除通常影响未命名寄存器；命名寄存器适合保留某段内容，避免后续删除覆盖要粘贴的文本。[Vim 寄存器参考](https://vimhelp.org/usr_27.txt.html)

Vim 内部的 `y/p` 不一定连接 Windows 剪贴板。`"+yy` 与 `"+p` 分别使用系统剪贴板寄存器复制／粘贴，需要 Vim 构建支持剪贴板且运行环境可访问它。可以用 `:echo has('clipboard')` 查看构建能力；返回 `1` 也不单独保证剪贴板服务可用。[Vim 系统剪贴板参考](https://vimhelp.org/gui.txt.html#clipboard)

## 6. Visual 选择与批量操作

| 按键 | 所在模式与作用 |
|---|---|
| `v` | Normal → 按字符 Visual 选择 |
| `V` | Normal → 按整行 Visual 选择 |
| `Ctrl+v` | Normal → 按矩形块 Visual 选择；若终端截获此键，则需检查终端映射 |
| `h/j/k/l` 等移动键 | Visual 中移动选区的活动端点 |
| `o` | Visual 中切换选区的活动端点，不是新建行 |
| `y` | Visual 中复制选区，返回 Normal |
| `d` | Visual 中删除选区，返回 Normal |
| `c` | Visual 中删除选区，进入 Insert |
| `>` / `<` | Visual 中将选中行向右／左缩进，随后返回 Normal |
| `=` | Visual 中按缩进规则重新缩进选中行 |
| `u` / `U` | Visual 中将选区文字变小写／大写；这里的 `u` 不是撤销 |
| `Esc` | 取消选择，返回 Normal |
| `gv` | Normal 中重新选中上一次 Visual 区域 |

要复制当前行和下面两行，依次按 `Vjjy`（共三行，并假设下面至少还有两行）：

1. `V`：进入整行 Visual 模式，当前行已经被选中。
2. `j`：将选区延伸到下一行，共两行。
3. 再按 `j`：选中第三行。
4. `y`：复制选区并返回 Normal。

然后在 Normal 中按 `p`，将复制的整行内容放到当前行下方。Visual 模式里应先完成范围选择，再按 `y`；第一次 `y` 已经完成复制并退出 Visual，因此 `vyy` 后再按向下键不会继续扩展原来的选区。

矩形块插入示例：`Ctrl+v` 选中多行开头 → `I` → 输入 `// ` → `Esc`。输入后退出插入模式时，文本才会应用到块内其他行。它适合演示批量加前缀；要给缩进不一致的 C++ 行添加注释，应先确认各行列位置。[Vim Visual 模式参考](https://vimhelp.org/visual.txt.html)

## 7. 组合规律与文本对象

常见组合是“操作 + 移动范围”，或“操作 + 文本对象”；前面还可加次数。移动命令如 `w` 可以独立使用，文本对象如 `iw` 通常跟在操作符后或用于 Visual 选择。

| 组合 | 含义 |
|---|---|
| `3yy` / `3dd` | 复制／删除三行 |
| `d2w` | 删除两次 `w` 移动覆盖的范围 |
| `diw` / `daw` | 删除词内部／词及相邻空白 |
| `ciw` | 修改整个词；从词中间开始也能作用于整个词 |
| `ci"` / `ca"` | 修改双引号内部／连同双引号一起修改 |
| `di(` / `da(` | 删除括号内部／连同括号一起删除 |
| `yi{` | 复制花括号内部的内容 |
| `vip` | Visual 选择当前段落内部 |

`i` 在 `ciw` 中表示 inner（内部），不是直接进入 Insert 的 `i`；`a` 在文本对象中表示 around（包含边界或周围内容），具体范围取决于对象。

例如光标位于 `"hello world"` 内，`ci"` 会保留双引号并让你重新输入内部文字；`ca"` 连引号一起修改。[Vim 文本对象参考](https://vimhelp.org/motion.txt.html#object-select)

## 8. 撤销、重做与重复编辑

| 按键（Normal） | 作用 |
|---|---|
| `u` | 撤销一次编辑变化 |
| `Ctrl+r` | 重做已撤销的编辑变化 |
| `.` | 重复上一次可重复的编辑操作 |
| `3.` | 以次数 3 重复上一次变化；具体效果取决于该操作，不等于任何情况下机械执行三次 |

例如先用 `ciw` 把某个词改成新词并按 Esc，再移动到另一个词按 `.`，可以重复同样的修改。`u` 是撤销，`U` 是整行撤销功能，二者不同。[Vim 撤销参考](https://vimhelp.org/undo.txt.html)、[重复操作参考](https://vimhelp.org/repeat.txt.html)

## 9. 搜索与替换

| 按键或命令 | 作用 |
|---|---|
| `/pattern` / `?pattern` | 向后／向前搜索模式，按 Enter 开始 |
| `n` / `N` | 按上次搜索方向／相反方向寻找下一处匹配 |
| `*` / `#` | 向后／向前搜索光标下的完整关键词 |
| `:set hlsearch` | 显示搜索匹配高亮 |
| `:nohlsearch` | 暂时清除当前高亮，下次搜索会再次显示 |
| `:set ignorecase` / `:set noignorecase` | 搜索忽略／区分大小写 |
| `:set smartcase` | 与 ignorecase 配合：模式含大写时区分大小写 |

`n` 不是固定向文件末尾：使用 `?` 向前搜索后，`n` 会继续向前搜索。搜索模式默认支持 Vim 正则表达式，`.`、`*` 等可能具有特殊含义。[Vim 搜索参考](https://vimhelp.org/pattern.txt.html)

| 替换命令（按 Enter 执行） | 范围与含义 |
|---|---|
| `:s/old/new/` | 当前行，按默认设置替换第一处匹配 |
| `:s/old/new/g` | 当前行，替换全部匹配 |
| `:%s/old/new/g` | 整个文件，替换全部匹配 |
| `:%s/old/new/gc` | 整个文件，替换前逐处确认 |
| `:10,20s/old/new/g` | 只在第 10 至 20 行替换 |

其中 `%` 表示所有行，`g` 表示每行全部匹配，`c` 表示确认。确认时可用 `y` 替换、`n` 跳过、`q` 结束。这里 `old` 是模式，不一定是字面字符串；完整标识符匹配示例为 `:%s/\<old\>/new/gc`。[Vim 替换教程](https://vimhelp.org/usr_10.txt.html#10.2)

## 10. 缩进与 C++ 编辑辅助

| 按键或命令 | 模式与作用 |
|---|---|
| `>>` / `<<` | Normal 下将当前行向右／左缩进一级 |
| `3>>` / `3<<` | Normal 下将当前行及下面两行向右／左缩进 |
| `==` | Normal 下重新缩进当前行 |
| `gg=G` | Normal 下重新缩进整个文件，依据当前文件类型和缩进规则 |
| `~` | 默认 Normal 下切换光标处字母大小写 |
| `gUiw` / `guiw` | Normal 下将当前词变大写／小写 |
| `Ctrl+a` / `Ctrl+x` | Normal 下增加／减少光标处或后面的可识别数值 |
| `:set autoindent` | 新行继承上一行缩进 |
| `:set expandtab` | 用空格插入制表符位置的缩进 |
| `:set tabstop=4 shiftwidth=4` | 设置 Tab 显示宽度和缩进宽度为 4 |

Vim 的重新缩进不等于完整的 C++ 格式化工具。上述 `:set` 设置通常只影响当前会话或相应缓冲区；若希望持久化，可另行整理到 `~/.vimrc`，本次未修改配置。[Vim 缩进参考](https://vimhelp.org/indent.txt.html)、[选项参考](https://vimhelp.org/options.txt.html)

## 11. 保存、退出与文件缓冲区

| 命令或按键 | 作用 |
|---|---|
| `:w` | 保存当前文件 |
| `:w filename` | 把当前缓冲区内容写入指定文件，不等同于所有场景下切换编辑目标 |
| `:saveas filename` | 另存并将当前缓冲区关联到新文件名 |
| `:q` | 关闭当前窗口；未保存修改可能阻止退出 |
| `:wq` / `:x` | 保存并关闭当前窗口；`:x` 仅在需要时写入 |
| `:q!` | 强制关闭当前窗口；退出最后窗口时放弃当前文件未保存修改 |
| `:qa` / `:qa!` | 退出所有窗口；带 `!` 放弃所有未保存修改 |
| `ZZ` / `ZQ` | Normal 下对应保存后关闭／强制关闭当前窗口 |
| `:e filename` | 编辑另一个文件；当前未保存修改可能阻止切换 |
| `:e!` | 重新载入当前文件，丢弃缓冲区的未保存修改 |
| `:ls` / `:buffers` | 查看缓冲区列表 |
| `:bn` / `:bp` | 切换到下一／上一缓冲区 |
| `:b 2` | 切换到编号为 2 的缓冲区 |
| `:bd` | 删除当前缓冲区；并不删除磁盘文件 |

缓冲区是 Vim 内存中正在编辑的文本，文件是磁盘上的内容，窗口是显示缓冲区的区域。多窗口时，关闭一个窗口不一定退出整个 Vim。[Vim 文件与缓冲区教程](https://vimhelp.org/usr_07.txt.html)、[保存退出参考](https://vimhelp.org/editing.txt.html#write-quit)

## 12. 分屏窗口与标签页

表格中的 `Ctrl+w → h` 表示先按 Ctrl+w，再按 h；`Ctrl+w` 单独按下时还在等待窗口操作键。

| 操作 | 作用 |
|---|---|
| `:split` / `:vsplit` | 上下／左右分屏显示当前缓冲区 |
| `:split filename` / `:vsplit filename` | 分屏并编辑指定文件 |
| `Ctrl+w → h/j/k/l` | 切换到左／下／上／右窗口 |
| `Ctrl+w → w` | 切换到下一个窗口 |
| `Ctrl+w → c` | 关闭当前窗口，未保存修改可能阻止关闭 |
| `Ctrl+w → o` | 只保留当前窗口，未保存修改可能阻止操作 |
| `Ctrl+w → =` | 将各窗口尺寸调整得尽可能均等 |
| `:tabnew filename` | 在新标签页编辑文件 |
| `gt` / `gT` | Normal 下切换到下一／上一标签页 |
| `:tabclose` | 关闭当前标签页 |

Vim 标签页是一组窗口的布局，不是简单的“一文件一标签”。同一个缓冲区可以在多个窗口显示。[Vim 窗口参考](https://vimhelp.org/windows.txt.html)、[标签页参考](https://vimhelp.org/tabpage.txt.html)

## 13. 标记、跳转与宏（进阶常用）

| 按键或命令（Normal 开始） | 作用 |
|---|---|
| `ma` | 在当前位置设置文件内标记 `a` |
| `'a` | 回到标记 `a` 所在行的第一个非空白字符 |
| `` `a `` | 回到标记 `a` 的准确行列位置 |
| `:marks` | 查看标记 |
| `Ctrl+o` / `Ctrl+i` | 在跳转列表中返回较早／前往较新的位置 |
| `qa` | 开始录制宏到寄存器 `a` |
| `q`（正在录制且处于 Normal） | 停止录制 |
| `@a` / `@@` | 执行寄存器 `a` 中的宏／重复最近执行的宏 |
| `3@a` | 执行宏 `a` 三次 |

宏记录按键序列，不是自动理解意图。录制前要选好起点，确保每轮执行后光标能到达下一轮需要的位置。宏与复制共用寄存器，例如 `qa` 会覆盖先前 `"ayy` 保存到 `a` 的内容；本次尚未完成宏实验。[Vim 标记与跳转参考](https://vimhelp.org/motion.txt.html#mark-motions)、[宏参考](https://vimhelp.org/repeat.txt.html#recording)

## 14. 显示设置、帮助与日常查阅

| 命令（按 Enter 执行） | 作用 |
|---|---|
| `:set number` / `:set nonumber` | 显示／关闭绝对行号 |
| `:set relativenumber` / `:set norelativenumber` | 显示／关闭相对行号 |
| `:syntax on` | 开启语法高亮，需安装相应运行时文件 |

查帮助时按 `Ctrl+]` 可跟随光标下的帮助标签，`Ctrl+t` 返回。用 `:q` 关闭帮助窗口。[Vim 帮助参考](https://vimhelp.org/helphelp.txt.html)、[选项参考](https://vimhelp.org/options.txt.html)

在 Ubuntu Shell 中运行 `vimtutor` 可以做交互练习；它不是在 Vim 中输入的 `:vimtutor` 命令。[Vim 入门手册](https://vimhelp.org/usr_02.txt.html)

日常优先记住：`Esc`、`i/a/o`、`hjkl`、`w/b`、`0/^/$`、`gg/G`、`yy/dd/p`、`V`、`u/Ctrl+r`、`/`、`:wq`。其他操作按任务需要查阅，不必一次全部背完。

## 建议练习（尚未执行）

在 Ubuntu Shell 中创建一个专用练习文件：

```bash
mkdir -p ~/projects/vim-practice
cd ~/projects/vim-practice
vim practice.txt
```

按 `i`，亲手输入以下三行，第一行开头保留四个空格：

```text
    alpha beta gamma
Linux is useful
Vim is interesting
```

随后按 `Esc`，依次练习：

1. 按 `gg`，比较 `0` 与 `^` 的光标位置。
2. 按 `o` 后输入 `j`，观察新行位置和实际插入的字符；按 `Esc` 后再按 `j`，比较区别。
3. 在 Normal 下用 `u` 撤销新增一行的修改，确认文件恢复为原来三行。
4. 按 `gg`，依次按 `Vjjy`，观察三行选区；再按 `G`、`p`，检查是否出现完整的三行副本。
5. 在 Normal 下按 `u` 撤销粘贴，再按 `Ctrl+r` 重做。
6. 输入 `:wq` 并回车，保存退出；在 Shell 中用 `cat practice.txt` 查看保存的内容。

练习后再记录：执行了哪些按键、看到了什么、是否有操作与预期不同。上述内容是预期检查点，当前没有实测结果。
