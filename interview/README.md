# Interview Preparation

本目录用于整理实习和未来校招相关的面试知识。

## Goal

这里不做传统意义上的“大而全八股文”。

主要记录：

> 我真正遇到过的问题。

> 我真正不会的问题。

> 当前岗位高频考察的问题。

## Topics

主要分为：

* C
* C++
* STM32 / MCU
* FreeRTOS
* Computer Architecture
* Linux
* OpenCV
* Networking
* Project

## Question Format

每一道值得记录的问题尽量按照：

```text
Question

My Answer

Correct Understanding

Why

Related Knowledge

Mistakes
```

整理。

例如：

```text
Question:
Mutex 和 Semaphore 有什么区别？

My Answer:
...

Better Answer:
...

Key Point:
...

Related:
Priority Inversion
Critical Section
```

## Interview Log

每次正式面试后记录：

```text
Company:
Position:
Date:

Questions:

1.
2.
3.

Things I Couldn't Answer:

1.
2.

What I Need to Learn:

1.
2.

Reflection:
```

目标：

> 每参加一次面试，都让自己的技术体系完善一点。

最终形成：

```text
Apply
 ↓
Interview
 ↓
Find Weakness
 ↓
Learn
 ↓
Update Repository
 ↓
Apply Again
```
