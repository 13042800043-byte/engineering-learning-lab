# Weekly Learning Log

本目录用于记录每周真实的技术学习进度。

Roadmap 记录：

> 我要去哪里。

Weekly Log 记录：

> 我实际上走到了哪里。

## Naming

按照年份和周数命名：

```text
2026-W37.md
2026-W38.md
2026-W39.md
...
```

## Principle

Weekly Log 不需要写成长篇日记。

重点记录：

> 做了什么。

> 哪里不会。

> 学到了什么。

> 下一步是什么。

长期目标是让这个目录成为自己的：

> Engineering Growth Timeline
